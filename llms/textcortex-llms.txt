# TextCortex

> TextCortex is a Berlin-based AI writing and content-generation platform. Its public REST API is OpenAI-compatible, exposing model discovery, chat completions, and responses over `https://api.textcortex.com/v1` with Bearer API-key authentication. Backed by Speedinvest.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's published OpenAPI and developer surface (no upstream llms.txt is published by TextCortex).

## API
- [TextCortex API (OpenAPI 3.0.2)](https://api.textcortex.com/v1/openapi.json): 5 operations — retrieveBalance, createChatCompletion, listModels, retrieveModel, createResponse. Base URL https://api.textcortex.com/v1. Auth: `Authorization: Bearer <api_key>`.
